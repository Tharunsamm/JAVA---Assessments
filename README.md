# JAVA---Assessment
## 📖 Overview

This repository contains my solutions to **15 Core Java programming questions** completed as part of **Assessment 1**. These exercises helped strengthen my understanding of Java fundamentals, including variables, data types, operators, mathematical calculations, user input, loops, methods, and Java's built-in classes.

All programs are written in **Java** using beginner-friendly coding practices with clear logic and comments.

## 📋 Questions Implemented

### 1. Area and Perimeter of a Rectangle
Calculates the area and perimeter based on user-provided length and width.

### 2. Convert Fahrenheit to Celsius
Converts temperature from Fahrenheit to Celsius.

### 3. Sum of Digits
Calculates the sum of all digits of an integer.

### 4. Minutes to Years and Days
Converts a given number of minutes into years and remaining days.

### 5. Current Time in GMT
Displays the current time in GMT using Java's Date-Time API.

### 6. Body Mass Index (BMI)
Calculates BMI using weight (pounds) and height (inches).

### 7. Speed Calculator
Calculates speed in:
- meters/second
- kilometers/hour
- miles/hour

### 8. Powers of a Number
Calculates:
- Square
- Cube
- Fourth Power

### 9. Break Integer into Digits
Breaks a six-digit integer into individual digits.

### 10. Compare Signed and Unsigned Numbers
Compares signed and unsigned integer values.

### 11. Floor Division and Floor Modulus
Demonstrates Java's `Math.floorDiv()` and `Math.floorMod()` methods.

### 12. Extract Primitive Values from BigInteger
Converts a `BigInteger` into primitive numeric types.

### 13. Next Floating-Point Number
Uses `Math.nextUp()` and `Math.nextDown()` to find adjacent floating-point values.

### 14. Floating-Point Operations
Performs floating-point calculations using Java's Math utilities.

### 15. Additional Java Mathematical Operations
Implements various mathematical operations using Java's built-in methods.
